## Pillar 3: ⚡ Data Fetching, Cache & State Architecture

### Supabase Database Queries:
```typescript
supabase.from('series')
  .select(`*, seasons (is_published, episodes (is_published))`)
  .eq('is_published', true)
  .order('created_at', { ascending: false });
```
- Fetches published series catalog from Supabase.
- Client-side `threeDFilteredSeries` useMemo filters for series matching `3d` or `cgi` tags.

### Client State Management:
- `searchQuery`: Text search filter input state.
- `sortMode`: `'a_z'` (Default), `'z_a'`, `'newest'`, `'oldest'`.
- `currentPage`: Active page index (25 items per page). Reset to `1` on search/sort changes.

## Pillar 5: ⚡ Performance & Core Web Vitals (CWV) Audit

- **Dynamic Revalidation Issue**:
  - `export const dynamic = 'force-dynamic'` and `revalidate = 0` currently force un-cached server renders on every user hit.
  - *Optimization Needed*: Remove dynamic flags, wrap Supabase query in `unstable_cache` with a 60s TTL, and reuse singleton public Supabase client instance to reduce TTFB to under 80ms.
