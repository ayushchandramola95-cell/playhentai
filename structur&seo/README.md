# 📐 Master Page Analysis & SEO Blueprint

This document defines the standard operating framework for conducting deep structural, technical, data, SEO, and performance analyses for every page on **PlayHentai** (`structur&seo/`).

---

## 🎯 Objectives of Page Analysis
For each page in the application, a dedicated markdown file will be created inside the `structur&seo/` directory (e.g., `structur&seo/homepage.md`, `structur&seo/watch_page.md`). Each document will provide an exhaustive breakdown across 8 critical pillars:

---

## 📋 Standard 8-Pillar Page Analysis Template

### Pillar 1: 📌 Page Overview & Routing Architecture
- **Route URL Pattern**: Exact path structure (e.g., `/watch/[episodeId]`, `/series/[slug]`).
- **File System Locations**: Target page component (`page.tsx`), CSS modules, layout wrappers, and API routes consumed.
- **Next.js Rendering Strategy**: Server Component vs. Client Component (`'use client'`), dynamic rendering (`force-dynamic`, ISR, static generation).
- **Access Control & Auth Guards**: Public access, logged-in user features, or admin authentication requirements.

### Pillar 2: 🧩 Visual & UI Component Structure
- **DOM & Section Hierarchy**: Full structural tree (Header, Hero/Player Section, Content Grids, Sidebars, Modals, Footer).
- **React Component Tree**: Child components used (`VideoPlayer`, `SeriesCard`, `HeroCarousel`, `AdBanner`, `WatchlistToggle`, etc.).
- **CSS Styling & Design System**: CSS Module classes, CSS variables (`var(--primary)`, `var(--surface)`), glassmorphism effects, and responsiveness breakpoints (Desktop, Tablet, Mobile).
- **Micro-Interactions & States**: Hover states, smooth transitions, skeleton loaders, and interactive state indicators.

### Pillar 3: ⚡ Data Fetching, Cache & State Architecture
- **Database Queries (Supabase)**: SQL tables queried (`series`, `episodes`, `seasons`, `bookmarks`, `site_settings`), joins, filters, and indexed column usage.
- **API Endpoints**: REST/Edge API routes consumed (`/api/settings`, `/api/comments`, etc.).
- **Client vs. Server State**: Server-side data props vs. client state (`useState`, `useContext`, URL `searchParams`).
- **Fallback & Error Handling**: Empty state behavior, 404 redirects, fallback to mock data pools, loading spinners.

### Pillar 4: 🔍 SEO & Search Engine Indexability Audit
- **Metadata Source & Generator**:
  - `Metadata Generated By`: Exact file location (e.g., `src/app/layout.tsx` or `src/app/(public)/watch/[episodeId]/page.tsx`).
  - `Metadata Type`: `Static Metadata` object vs. `dynamic generateMetadata()` function.
- **Search Intent & SEO Goal**:
  - `Primary Intent`: Core user intent targeted by the page (e.g. Browsing vs. Watching).
  - `Secondary Intent`: Sub-intents (e.g. Filter by genre, studio, release year).
  - `SEO Goal`: Broad ranking target vs. specific title ranking target.
- **Target Keyword Strategy**:
  - `Primary Keyword`: Main search query targeted by the page.
  - `Secondary Keywords`: Related semantic topics, search modifiers, and entity keywords.
  - `Primary Terms Present`: Objective verification of essential keywords present in metadata (`Watch`, `Browse`, `Uncensored`, `Hentai`, `HD`, `Brand Name`).
- **Filter URLs & Search Engine Treatment**:
  - `Supported Parameters`: Query parameters supported (`?genre=`, `?studio=`, `?year=`).
  - `Indexed?`: Whether parameters create separately indexable pages or share base metadata.
  - `Canonicalized?`: Self-canonical vs parameter canonical rules.
  - `Duplicate Content Prevention?`: Parameter canonicalization rules.
- **Pagination SEO Breakdown**:
  - `Pagination Parameter`: URL query parameter (`?page=2`) vs React state.
  - `Canonical`: Self-referential vs page 1 canonical.
  - `Prev / Next Links`: `<link rel="prev">` / `<link rel="next">` header tag status.
  - `Infinite Scroll`: Infinite scroll vs fixed numbered pagination.
- **Technical Crawlability Matrix**:
  - `Included in Sitemap`: `Yes` / `No`
  - `Self Canonical`: `Yes` / `No`
  - `Noindex`: `No` / `Yes`
  - `Robots Directives`: `index`, `follow`, `googleBot`, `max-image-preview`, `max-video-preview`
  - `Pagination`: `None` / `Numbered (25 items/page)` / `Infinite Scroll`
- **Dynamic Metadata Audit**:
  - `title` tag format, length, and keyword placement.
  - `description` tag length and click-through term composition.
  - Canonical URL structure (`process.env.NEXT_PUBLIC_SITE_URL` + route).
  - OpenGraph tags (`og:title`, `og:description`, `og:image`, `og:type`, `og:url`).
  - Twitter Card tags (`summary_large_image`).
  - Robots directives (`index, follow` vs `noindex`).
- **Semantic HTML & DOM H1 Verification**:
  - Audit of `<h1>` tags: Confirm if inactive elements (e.g. hero carousel slides) are conditionally unmounted from HTML (`return null`) vs. hidden via CSS (`display: none`) to ensure Google sees strictly 1 single `<h1>` tag in HTML output.
  - Heading distribution (`<h2>`, `<h3>` hierarchy audit).
- **JSON-LD Rich Snippets & Structured Data**:
  - **Implemented Schemas**: `WebSite`, `VideoObject`, `TVSeries`, `BreadcrumbList`, `ItemList`.
  - **Intentionally Omitted / Not Implemented Schemas**: Explicit list of schemas not present (e.g. `Organization`, `WebPage`, `FAQPage`) so future developers/AI know what was intentionally left out.
- **Internal Linking Map (`Page Links To`)**:
  - Comprehensive map of outgoing internal links (Series, Episodes, Genres, Tags, Studios, Search, Latest, Trending, Collections) for crawl equity tracking.
- **Image & Asset SEO**: Image `alt` attributes, WebP/AVIF formats, explicit width/height parameters, Cloudflare R2 CDN delivery.

### Pillar 5: ⚡ Performance & Core Web Vitals (CWV)
- **LCP (Largest Contentful Paint)**: Hero image/video player preloading strategy (`priority`, `fetchpriority`).
- **CLS (Cumulative Layout Shift)**: Reserved image aspect ratios, fixed layout boundaries, skeleton loading prevention.
- **INP / FID (Interaction to Next Paint)**: Execution delays, heavy re-renders, input debouncing.
- **Bundle & Asset Footprint**: Code splitting, icon tree-shaking, lazy-loaded components.

### Pillar 6: 💰 Monetization, Ads & Analytics
- **Ad Placements**: VAST in-stream video pre-roll, native display banners, popunder triggers, sticky footer banners.
- **Ad Blocker Resilience**: Fallback layout height preservation to prevent layout shifts.
- **Analytics & Tracking**: Event hooks and view counters (`views` column updates).

### Pillar 7: ♿ Accessibility (a11y) & Mobile UX Hygiene
- **ARIA & Keyboard Navigation**: `aria-label`, button focus rings, modal focus trapping, tab indexes.
- **Touch Target Sizing**: Mobile minimum 48px touch targets for touch devices.

### Pillar 8: 🛠️ Exhaustive Actionable Improvement Plan
- **Prioritized Checklist**:
  - 🚨 **Critical Bugs**: Fixes for broken links, missing props, or crashes.
  - 🚀 **High-Priority SEO Fixes**: Missing metadata, missing schema fields, heading fixes.
  - ⚡ **Performance Enhancements**: LCP/CLS optimizations.
  - 🎨 **UI/UX Refinements**: Spacing, mobile responsiveness, visual feedback.
