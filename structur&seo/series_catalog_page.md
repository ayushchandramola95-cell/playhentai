# 📚 Series & Categories Catalog Page Deep Architectural & SEO Audit (`structur&seo/series_catalog_page.md`)

This document presents an exhaustive, 8-pillar structural, technical, data, SEO, and performance analysis of the **Series & Categories Catalog Page** (`/categories` / `Browse Library`).

---

## Pillar 1: 📌 Page Overview & Routing Architecture

- **Route URL Pattern**: `/categories` (Supports query parameters: `?genre=Action`, `?studio=PoRO`, `?year=2026`, `?sort=a_z`).
- **File System Locations**:
  - **Main Page Component**: `src/app/(public)/categories/page.tsx`
  - **Child Filter Hub Component**: `src/components/BrowseHub/BrowseHub.tsx`
  - **CSS Modules**: `src/app/(public)/categories/categories.module.css` & `src/components/BrowseHub/BrowseHub.module.css`
  - **Public Layout Wrapper**: `src/app/(public)/layout.tsx`
  - **Constants File**: `src/utils/constants.ts` (`GENRES`, `STUDIOS`, `RELEASE_YEARS`).
- **Next.js App Router Rendering Strategy**:
  - Server Component (`page.tsx`) fetches published series from Supabase and passes them as initial props to `<BrowseHub>` Client Component (`'use client'`).
  - Wrapped in `<React.Suspense>` to handle URL `useSearchParams()` hydration without breaking static/SSR builds.
- **Access Control & Auth Guards**:
  - **Public Access**: 100% accessible to all users.

## Pillar 3: ⚡ Data Fetching, Cache & State Architecture

### Supabase Database Queries:
```typescript
supabase.from('series')
  .select(`*, seasons (is_published, episodes (is_published))`)
  .eq('is_published', true)
  .order('created_at', { ascending: false });
```
- Fetches all published series from Supabase.
- If database is empty, falls back to rich mock series data (`MOCK_SERIES`).

### Client State Management:
- `activeTab`: `'genres' | 'studios' | 'years'` (Default: `'genres'`).
- `selectedGenre`, `selectedStudio`, `selectedYear`: Active filter states.
- `searchQuery`: Controlled text search query.
- `sortMode`: `'a_z'` (Default: Name A-Z), `'z_a'`, `'newest'`, `'oldest'`, `'most_viewed'`, `'rating'`.
- `currentPage`: Page index (25 items per page). Automatically resets to `1` whenever filters change.

## Pillar 4: 🔍 SEO & Search Engine Indexability Audit

### Metadata Source & Generator:
- **Metadata Generated By**: `src/app/(public)/categories/page.tsx` (`export const metadata`)
- **Metadata Type**: `Static Metadata` object

### Search Intent & SEO Goal:
- **Primary Search Intent**: Browse the complete anime catalog.
- **Secondary Search Intent**: Discover anime by genre, studio, and release year.
- **SEO Goal**: Rank for broad browsing keywords (`browse hentai anime`, `hentai categories`, `hentai genres`, `hentai series`, `uncensored hentai library`), **not** individual anime titles.

### Target Keyword Strategy & Primary Terms:
- **Primary Keyword**: `browse hentai anime` *(Catalog & browsing intent)*
- **Secondary Keywords**: `hentai categories`, `hentai genres`, `hentai series`, `uncensored hentai library`
- **Primary Terms Present**:
  - `Browse` (Present in Meta Description & H1)
  - `Uncensored` (Present in Title Tag & Meta Description)
  - `Hentai` (Present in Title Tag & Meta Description)
  - `Anime` (Present in Title Tag & Meta Description)
  - `Categories` (Present in Title Tag & Meta Description)
  - `Brand Name` (`PlayHentai` present in Title Tag & Meta Description)

### Filter URLs & Search Engine Treatment:
- **Supported Parameters**: `?genre=`, `?studio=`, `?year=`
- **Search Engine Treatment Breakdown**:
  - `Indexed?`: Currently indexed under the main `/categories` URL. Parameter variations load the same base metadata.
  - `Canonicalized?`: Yes (Self-canonicalized to `https://playhentai.live/categories`).
  - `Noindex?`: No.
  - `Duplicate Content Prevention?`: Self-canonicalization prevents duplicate content indexing for minor filter variations.
  - `Potential Enhancement`: Implement dynamic `generateMetadata({ searchParams })` for filter parameters (e.g. `/categories?genre=Schoolgirl` $\rightarrow$ Title: `Schoolgirl Hentai Anime | PlayHentai`) to enable indexable category landing pages.

### Pagination SEO Breakdown:
- **Pagination Parameter**: `?page=2` (Currently managed in React component state; recommended to sync to URL query string).
- **Canonical URL**: Self-referential (`https://playhentai.live/categories`).
- **Prev / Next Links**: Not Implemented (`<link rel="prev">` / `<link rel="next">` tags omitted).
- **Infinite Scroll**: `No` (Uses fixed 25 items per page with numbered pagination controls).

### Technical Crawlability Matrix:
- **Included in Sitemap**: `Yes` (via `/sitemap.ts`)
- **Self Canonical**: `Yes` (`https://playhentai.live/categories`)
- **Noindex**: `No` (`index: true, follow: true`)
- **Robots Directives**: `index: true`, `follow: true`, `googleBot: { index: true, follow: true, max-image-preview: 'large', max-video-preview: -1, max-snippet: -1 }` (Inherited from Root Layout)
- **Pagination**: `Numbered` (25 items per page)

### Dynamic Metadata Inspection:
- **Title Tag**: `Watch Uncensored Hentai Anime Series & Categories`
  - *Evaluation*: 47 characters (optimal under 60 chars). Target terms present: `Watch`, `Uncensored`, `Hentai`, `Anime`, `Series`, `Categories`.
  - *SEO Improvement Recommendation*: Change title from `Watch...` to `Browse Hentai Anime Categories & Series` or `Browse Uncensored Hentai Anime Library` to match browsing catalog user intent.
- **Meta Description**: `Browse all anime genres, categories, release years, and studios. Filter uncensored anime series by your favorite tags on PlayHentai.`
  - *Evaluation*: 140 characters (optimal under 160 chars). Target terms present: `Browse`, `Genres`, `Categories`, `Studios`, `Uncensored`, `Hentai`, `PlayHentai`.
- **Canonical URL**: `https://playhentai.live/categories`
- **OpenGraph Metadata**: `og:title`, `og:description`, `og:url`, `og:type` (`website`).

### Semantic HTML & DOM H1 Verification:
- **`<h1>` Verification**:
  - *Current H1*: `<h1>Browse Library</h1>` in `page.tsx` (line 127).
  - *Result*: **Passed (100% Single H1 HTML DOM)**.

## Pillar 5: ⚡ Performance & Core Web Vitals (CWV) Audit

- **Instantaneous Filtering**:
  - Filtering and sorting happen in-memory on the client without full page reloads or API roundtrips.
- **Layout Shift Prevention (CLS)**:
  - Series card images use fixed `aspect-ratio: 2 / 3`.
- **SSR Revalidation**:
  - Database queries should be cached using Next.js `unstable_cache` with a 60-second TTL to improve initial SSR response time.
