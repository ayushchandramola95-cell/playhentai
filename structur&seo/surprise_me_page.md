## Pillar 3: ⚡ Data Fetching, Cache & State Architecture

### Database Query:
```typescript
const getCachedRandomizerSeries = unstable_cache(
  async () => {
    const { data } = await publicSupabaseClient.from('series').select('*').eq('is_published', true);
    return data || [];
  },
  ['randomizer-series-cache-v1'],
  { revalidate: 60, tags: ['randomizer_catalog'] }
);
```

### Client State Management:
- `selectedGenre`: `'all'` (Default), `'uncensored'`, `'action'`, `'fantasy'`, `'harem'`, `'scifi'`. Synced from URL query parameter `?genre=`.
- `isSpinning`: Boolean state during slot machine reel animation.
- `slotImageIndex`: Animated frame counter for reel poster preview.
- `winner`: Currently selected random series item.
