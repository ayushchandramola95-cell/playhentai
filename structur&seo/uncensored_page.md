## Pillar 3: ⚡ Data Fetching, Cache & State Architecture

### Supabase Database Queries:
```typescript
supabase.from('series')
  .select(`*, seasons (is_published, episodes (is_published))`)
  .eq('is_published', true)
  .order('created_at', { ascending: false });
```
- Fetches published series catalog from Supabase.
- Falls back to rich mock data pool (`MOCK_SERIES`) if database is empty.

### Client State Management:
- `searchQuery`: Text search filter input state.
- `sortMode`: `'a_z'` (Default), `'z_a'`, `'newest'`, `'oldest'`.
- `currentPage`: Active page index (25 items per page). Automatically resets to `1` whenever search query or sort mode changes.
