- **Route URL Pattern**: `/search` (Dynamic search parameters e.g. `https://playhentai.live/search?q=cyberpunk`).
- **File System Locations**:
  - **Main Page Component**: `src/app/(public)/search/page.tsx`
  - **CSS Modules**: `src/app/(public)/search/search.module.css`
  - **Supporting Components**: `SeriesCard.tsx`, `Header.tsx` (Search Bar Input)

  - Server Component resolving `searchParams` (`Promise<{ q?: string }>`), querying Supabase `series` table via `title.ilike.%q%` OR `description.ilike.%q%`, and rendering responsive grid of `<SeriesCard>`.
- **Access Control & Auth Guards**:
  - **Public Access**: 100% accessible to all users.

## Pillar 3: ⚡ Data Fetching, Cache & State Architecture

### Database Queries:
```typescript
const getCachedSearchResults = unstable_cache(
  async (query: string) => {
    if (!query) return { results: [], isDbEmpty: false };
    const { data } = await publicSupabaseClient
      .from('series')
      .select('*, seasons(is_published, episodes(is_published))')
      .eq('is_published', true)
      .or(`title.ilike.%${query}%,description.ilike.%${query}%`);
    return { results: data || [], isDbEmpty: false };
  },
  ['search-results-cache-v1'],
  { revalidate: 60, tags: ['search_results'] }
);
```

## Pillar 4: 🔍 SEO & Search Engine Indexability Audit

### Metadata Source & Generator:
- **Metadata Generated By**: `src/app/(public)/search/page.tsx` (`generateMetadata({ searchParams })`)
- **Metadata Type**: Dynamic Metadata function

### Search Intent & SEO Goal:
- **Target User Intent**: Internal catalog search & keyword exploration (`?q=...`).
- **SEO Goal**: **Internal Search Optimization**. Comply with Google Search Essentials guidelines by serving **`noindex, follow`** metadata on internal search parameter pages to prevent crawl budget dilution while allowing crawlers to discover and follow links to individual series pages.

### Technical Crawlability & Indexability Matrix:
- **Included in Sitemap**: `No` (Internal search parameter URLs excluded from `/sitemap.ts`)
- **Self Canonical**: `Yes` (`https://playhentai.live/search`)
- **Noindex / Follow Directives**: `Yes` (`robots: { index: false, follow: true }`) - *Follows Google Search Essentials best practices*
- **Pagination**: `None`

### Dynamic Metadata Inspection:
- **Title Tag**: `q ? `Search results for "${q}" | PlayHentai` : 'Search Hentai Anime Catalog | PlayHentai'`
- **Meta Description**: `Find and watch anime series matching "${q}". Search by title, alternative names, studio, or genre tags on PlayHentai.`
- **Canonical URL**: `https://playhentai.live/search`

### Semantic HTML & DOM H1 Verification:
- **`<h1>` Verification**:
  - *Current H1*: `<h1>{query ? `Search Results for "${query}"` : 'Search Hentai Anime Catalog'}</h1>` in `page.tsx`.
